# Welcome to my corner on the internet

I am a software engineer in Bengaluru who prefers terminals over dashboards and plain text over ornamental UI. This rebuild turns the portfolio into a shell: a small command surface for the work, writing, and links that matter.

Start with `help` to see what is installed, use `man <command>` to inspect a command before running it, and use `clear` when you want a truly blank terminal.
